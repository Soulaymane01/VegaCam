# 🎥 Viga Cam - Security & Comfort Solutions

[![Next.js](https://img.shields.io/badge/Next.js-15-black?style=for-the-badge&logo=next.js)](https://nextjs.org/)
[![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-3.4-38B2AC?style=for-the-badge&logo=tailwind-css)](https://tailwindcss.com/)
[![Framer Motion](https://img.shields.io/badge/Framer_Motion-11-ff0055?style=for-the-badge&logo=framer)](https://www.framer.com/motion/)

A premium, high-performance landing page for **Viga Cam**, a specialized provider of security camera installations and air conditioning systems. This project showcases modern web development practices, focusing on performance, accessibility, and a premium user experience.

## ✨ Key Features

-   **🚀 Modern Stack**: Built with Next.js 15 (App Router), TypeScript, and Tailwind CSS.
-   **🎨 Premium UI/UX**: Designed with a focus on clean aesthetics, smooth transitions (Framer Motion), and responsive layouts.
-   **📱 Fully Responsive**: Seamless experience across mobile, tablet, and desktop devices.
-   **🛠 Specialized Services**: Showcases core offerings including surveillance systems, HVAC solutions, and electronic maintenance.
-   **⚡ Performance Optimized**: Leveraging Next.js image optimization and server components.
-   **📧 Interactive Elements**: Integrated contact forms, dynamic service cards, and automated carousels.

## 🛠 Tech Stack

-   **Framework**: [Next.js 15](https://nextjs.org/)
-   **Styling**: [Tailwind CSS](https://tailwindcss.com/)
-   **Animations**: [Framer Motion](https://www.framer.com/motion/)
-   **Icons**: [Lucide React](https://lucide.dev/)
-   **Slider**: [Swiper.js](https://swiperjs.com/)
-   **Components**: [Radix UI](https://www.radix-ui.com/) / [shadcn/ui](https://ui.shadcn.com/)

## 🚀 Getting Started

### Prerequisites

-   Node.js 18.x or later
-   npm or yarn

### Installation

1.  Clone the repository:
    ```bash
    git clone https://github.com/Soulaymane01/VegaCam.git
    cd VegaCam
    ```

2.  Install dependencies:
    ```bash
    npm install
    ```

3.  Run the development server:
    ```bash
    npm run dev
    ```

4.  Open [http://localhost:3000](http://localhost:3000) in your browser.
